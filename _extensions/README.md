## SCSS guides
  - cme/cme_theme/cme_light.scss and cme/cme_theme/cme_dark.scss <- contains light or dark palettes describing web layout; this is where you change the color scheme
  - cme/cme_theme_independent.scss <- contains settings that are independent of color themes, for example headshot layouts, cards, etc.
