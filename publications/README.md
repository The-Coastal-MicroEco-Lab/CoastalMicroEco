
## To add a publication:
1. go to the publication's website and find the "cite" button.

2. When asked which form to download select the ".bib" or "BibTex" option.
3. Download the .bib file to the bibliography folder.

That's it! (.bib files can contain multiple entries, if you want to download a 
google scholar profile, for example)


## If the _publications.qmd file is missing
First run `python scripts/generate_publications.py` from the home directory. 
Then try rendering the website again.
