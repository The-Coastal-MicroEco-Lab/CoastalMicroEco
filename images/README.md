## Images
This folder is for storing images to be hosted on the webpage. Be mindful of size since github has repository limits. 

 - profiles - contains headshots of group members. Alumni headshots are not displayed so it's okay to remove them
 - Other images - for better organization and management, arrange in folders based on where they are used, for example "posts/" for images in blog posts or announcements, "projects/" for images in projects, etc. If an image will be used in mutiple places, it's better to put it in a "shared/" folder so that anyone trying to delete it is aware of that it might break several pages.
